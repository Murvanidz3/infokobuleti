# Project instructions — infokobuleti.com

- Product: infokobuleti.com, local portal for Kobuleti (Georgia). Full style spec lives in `DESIGN-PROMPT.md`; decisions log in `MEMORY.md`. Read both before designing any new page.
- Source of truth for the visual system: `Homepage.dc.html`. Reuse its header, footer, cards, buttons, spacing and hover effects verbatim on every new page.
- All UI copy in Georgian; realistic Kobuleti placeholder content (₾ prices, real street names). No lorem ipsum.
- Colors: navy `#0a1a2f` dominant; coral `#d4602a` is the only action/accent color (buttons, CTA, hover fills, hearts, “ახალი”, prices as `#b44f1e`). Tints `#e8edf3`, `#c9d3df`, `#f5f7fa`, secondary text `#3a4a5f`. Do not introduce new bright colors.
- Fonts: Noto Sans Georgian (UI), Noto Serif Georgian (headings), Outfit (logo only).
- Logo: wordmark only — “info” light + “kobuleti” bold, coral glowing dot over the last “i”. No icon mark.
- Line icons only, 1.5px stroke, no emoji.
- Keep it airy and minimal; subtle motion only.
- The user writes in Georgian — reply in Georgian, concisely.
